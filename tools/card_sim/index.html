通常UI

画面右上のタッチ、Escapeでログ、Ctrl-Lでスプラッシュ。長押し・ドラッグ・複数指では切り替わりません。

画面とカード

PINと結果画面はタッチで操作できます。数字キーはどれも「1桁追加」です。キーボードの数字 / Backspace / Enter / Escape はPIN画面用です。実際のPINは入力しないでください。

フレーム境界

自動EOFを外すと、公開待ちの間は旧フレームが保持されます。

画面: 本番の増分レンダラ / 比較: 全画面再描画とのバイト比較。表示更新の境界はホストモデルで、実機DMA・キャッシュ・時間測定は対象外です。

再現用トレース

操作を保存

保存するのは桁数変化と画面操作だけです。タッチ座標、数字、カード情報は含みません。通常UIのトレースは座標・接点数・時間差・キュー処理を保存します。カード／PINのトレースとは別形式です。
