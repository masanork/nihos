# はじめに

小さなOSなら、CPUが命令を実行するところから、画面に文字が現れるところまで、自分で追えるだろうか。私はnihosを作りながら、そのつながりを確かめている。本書はM5Stack Tab5を実験機に、OSの仕組みと設計を選ぶ理由を学ぶ本である。

作り始めたきっかけは、MeOSを見て面白いと思ったことだった。手を入れて拡張するうちに、せっかくなら自分の好きな設計で一から作ってみたくなった。M5Stackで動くさまざまなOSや、FreeRTOSのSMP対応も、作り始めてから知った。本書には、そのような発見と、実験を通して考え直したことも残したい。

画面のバッファを誰が書き換えてよいか。割込み中に何をしてよいか。別のCPUへ渡した仕事を途中で止めたら、誰が片づけるか。守る条件をコードと実験で確かめることが、システムを作る仕事になる。

本書は、端末とOSの役割を確かめ、M5StackのOSとアプリ環境を見渡した後、起動、タスク、実行権限とメモリ保護、メモリの配分、CPU間通信へ進む。次に入出力の寿命を学び、表示、無線、複数のデバイスを調べる。ファイルと保存、重い計算サービス、SQLiteの復旧を経て、ICカード端末としてつなぐ。最後に浮動小数点と言語選択を、これまでの実例へ戻って考える。[序章](why-os.md)では、OSを学ぶ意味とnihosの出発点を考える。

読者にはCなどで関数、ポインタ、構造体を使った経験を想定する。OSの実装やTab5の知識は前提にせず、必要な機械の仕組みを本文で紹介する。Zigの記法は登場したところで説明する。結果を予想してからコードを読み、手元の実験と比べてほしい。

実習はPC上のテストと生成コードの検査が中心で、Tab5がなくても取り組める。追加のエミュレータ実験と実機の観測も読み合わせる。必要な版と環境は、巻末の[実習環境](practice-notes.md)にまとめた。
