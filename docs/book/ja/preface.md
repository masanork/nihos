# はじめに

小さなOSなら、CPUが次の命令を実行するところから、指で触れた位置に画面が応答するところまで、自分で追えるだろうか。本書ではM5Stack Tab5上のnihosを教材に、そのつながりを調べる。

画面のバッファを誰が書き換えてよいか。割り込み中に何をしてよいか。別のCPUへ渡した仕事を途中で止めたら、誰が片づけるか。守る条件をコードと実験で確かめることが、システムを作る仕事になる。

この試読版では、既存ソフトウェアとの境界、host上の実験、有限メモリの割当、Zigへ入るまでの準備を追う。ESP-IDF側の実装と、nihosが起動後の責任を担うnative経路を比べながら読む。

読者にはCなどで関数、ポインタ、構造体を使った経験を想定する。Zigの記法は登場したところで説明する。

必須実験はPC上のテストとELF検査で完結する。ESP-EMUでの起動は追加の実験とし、Tab5の周辺機器を含む実験とは区別する。

実行前に、何が起こるかを一度予想してほしい。予想と結果が違ったところに、自分の理解と機械の動きの境界がある。
