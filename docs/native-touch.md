# PINなしの表示・タッチ結合試験

Tab5内蔵タッチの追加配線は不要で、GPIO31/32の内部I2Cから読み出す。
この変更は、確認済みのSRAMロゴ表示経路にタッチ座標による背景色変更を加える。
PIN画面やカード認証の前に、四象限の座標、接触、離指表示を確かめるための試験。

```sh
NIHOS_NATIVE_DISPLAY=6 NIHOS_NATIVE_TOUCH_CHECK=1 sh tools/build-native.sh device integer
```

USB/JPKI/CARD_CHECKとの併用はビルド時に拒否する。
起動時の既存CPU・メモリ検証が終わった後、CPU0がI2Cとタイマを専有し、
USB-A給電制御をOFFにしてから読み出す。カードAPDU、PIN入力、数字の保存はない。
ログに含めるのは、この操作確認での座標、接触数、背景色と件数だけ。

ロゴが正立する向きで、左上・右上・左下・右下を順番に押し、各回で指を離す。
座標に対応する色は赤・緑・青・黄。離指表示は元の暗い背景。
ロゴの画素やDMAディスクリプタはタッチ処理で書き換えない。
背景色の更新とキャッシュ同期中だけCPU0割込みを抑止し、ROMの
キャッシュ操作を表示IRQから再入しないようにする。

表示依存コードは、並行作業中の `codex/native-boot-graphics` の
`10a4cb6` 以降の作業コピーから独立したコピーへ固定した。
[元ファイルのハッシュ](measurements/2026-10-27-touch-display-dependency.json)を保持する。
元の作業ツリーは変更していない。今回有効にするのはロゴのmode 6だけで、
未使用のscene経路はコンパイルから除外し、既存48 KiBの内部ヒープ下限を保つ。
元の表示ブランチの実機結果を、この変更後のイメージの証拠として流用しない。

`touch_feedback.State` はPIN処理から独立している。
Sitronixの座標なし応答が2回続いた場合、この試験では離指表示へ戻す。
これは推定離指として、明示的なゼロ接触報告と別に記録する。
Goodixの更新なし応答では離指を推定しない。この推定をPIN確定には使わない。

4象限と離指を観測するか60秒経過すると1回のチェックポイントを出力し、
その後も色変更を継続する。I2C・キャッシュ・表示の異常は失敗として出す。
表示32フレーム以上、座標と色の整合、四象限と離指のイベントを
`check-native-touch-log.py` で照合する。画面の可視性はユーザーの観察で別に確認する。

```sh
python tools/capture-native-usb.py PORT OUTPUT build/native-device/image-audit.json \
  --install build/native-device --touch --runs 1
```

このキャプチャは固定イメージ、排他的シリアル、前後のFlash照合、
既存ネイティブ検証、表示IRQとタッチのログを同じ接続で確認する。
最終照合後に再起動するため、確認後も同じタッチ試験が動く。
