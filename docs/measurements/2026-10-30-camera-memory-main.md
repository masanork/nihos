# Pre-DMA camera workspace on the current integration base (2026-10-30)

After reconnecting Tab5, one physical trial exercised the default-off `:csi-memory` fixture on base `d824feaa8acc66dc16810fc9fa95887f5efc642d` plus the uncommitted camera integration worktree. The requested 921,600-byte frame was pinned in the CPU0 task-owned PSRAM heap; the workspace performed 1,024-byte cache writeback and invalidate steps, zeroed the buffer, wrote back its contents, and released the pinned allocation without ever starting DMA. Final state 3/result 0 means the workspace returned to idle after release. These are software state and cache-API return observations; there was no independent full-memory zero readback.

Device ESP32-P4 rev 1.3, MAC `e8:f6:0a:e2:e8:9c`; application SHA-256 `6a27bc5f68c735b7f09f40ea7bde8ba3d9b5ef0988c0fb9d62103ff3156793bf`, ELF SHA-256 `8d1357f5a68c1d798b8d037a2d24621cf2aa15f5f4017c350a3835789efe6bd9`. [Receipt and image audit](evidence/2026-10-30-camera-memory-main/). The explicit kind 9 request was accepted; periodic reports observed preparation, erasure, and two repeated terminal reports. Display frames and both CPU tick counters advanced across the request. Reports are observations of one trial, not repeated independent captures.

The transaction acquired the agreed write lock and exclusive serial ownership, confirmed board identity, froze and verified candidate bytes, restored the original loader and app erase spans (24,576 and 151,552 bytes) and verified full readback, then issued a hard reset. Restored-system boot was not captured. Raw serial logs remain private. The earlier attempted run stopped before device open because the serial port was absent and performed no device writes.

No CSI or DMA transfer was started. This trial does not establish PSRAM DMA reachability, completion, FIFO/IRQ drain, safe reuse after an active transfer, camera output, power-cycle durability or full UI/input coexistence. The host pin/extent-group tests and ledger size analysis are recorded separately in [host evidence](2026-10-30-camera-pin-main-host.md).
