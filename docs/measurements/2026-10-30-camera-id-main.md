# Camera identity on the current OS integration base (2026-10-30)

Base `d824feaa8acc66dc16810fc9fa95887f5efc642d`, with the uncommitted camera integration worktree. The explicit `NIHOS_NATIVE_CAMERA_ID=1` fixture attaches the one-shot camera power/identity state machine to the existing CPU0 board I2C owner. The `:camera-id` request is accepted only when the fixture is enabled and the board service is active. It powers the camera through the shared expander using masked read-modify-write, waits at least 100 ms after power-on, reads both ID bytes, then turns power off and verifies register readback. Cleanup failure pins the probe. The default build disables the fixture; no CSI or frame capture is wired on this base.

One Tab5 ESP32-P4 rev 1.3 physical run, MAC `e8:f6:0a:e2:e8:9c`; app SHA-256 `6a895cc5b15f5bc778d1ca2024f5c743c9a54104d85510d2bd585bae5a5b7918`, ELF SHA-256 `9f9d37b7714e72c7ea83ee2117eb5474477ae7402531f1eb007b5e9df0c2d09d`. [Receipt and image audit](evidence/2026-10-30-camera-id-main/). After two idle reports, the explicit serial request was accepted. The sensor matched expected ID `0xeb52`, and two repeated terminal reports showed `state=5 result=1`, meaning identity and expander OFF readback completed. The launcher became ready; display frames and both CPU tick counters advanced across the request. This does not prove optical image capture, actual power rail voltage, touch or audio coexistence, or a cold power cycle.

Host tests cover shared-expander mask preservation, ID mismatch, clock and transport failures, cleanup failure, and the bounded parser. The vendored SC202CS register sequence and Apache-2.0 license retain their pinned source and generator; its mode/stream paths are not exposed by this fixture and were not tested on this candidate. The original loader and app spans (24,576 and 147,456 bytes) were restored and fully verified, followed by a hard reset; restored-system boot was not captured. The prior worktree's transaction/qualification script and shared hardware write lock were used. Raw serial data remain private.
