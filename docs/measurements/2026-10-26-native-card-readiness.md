# Native Input Support / touch readiness

2026-10-26 JST。実機イメージのソースは
`a6006c759cab06e4bb7cb6f48a0194561a0485fa`。
カードへのPIN送信、四属性の認証読取、PIN画面の実機表示は行っていない。
後続の日本語PIN画面はホスト描画として別に検証している。

## 実機で確認した範囲

M5Stack Tab5 / ESP32-P4 rev1.3、32 MiB PSRAM、SONY RC-S300
`054c:0dc9`。ST7121のタッチ情報は720×1280・10スロットだった。

同一の排他的シリアル接続をインストール、Flash照合、3回のRTS起動、
最終Flash照合まで保持した。3回とも既存の300ラウンド、タスク終了、
IPI/idle、所有メモリ、USB起動診断の厳密な検査を通った。
その後、CPU0がタイマ、I2C、USBを専有して次を行った。

1. USBを再列挙し、CCIDでカードを起動する。
2. 入力補助AP、PIN EF0011を選択し、データなしVERIFYで残り回数を読む。
3. PINを入力せずに終了し、DMAコピーを消去する。
4. USB-A給電制御をOFFにし、ラッチ・方向・高インピーダンス設定を読み返す。
5. タッチを64回サンプリングする。

| 項目 | 起動1 | 起動2 | 起動3 |
| --- | --- | --- | --- |
| 入力補助PINの残り回数 | 3 | 3 | 3 |
| PIN送信 | 0 | 0 | 0 |
| CCID電源OFFの応答状態 | active | active | active |
| 終了方式 | 給電OFFへ切替 | 給電OFFへ切替 | 給電OFFへ切替 |
| DMA消去 / 給電OFF読返し | 成功 | 成功 | 成功 |
| タッチ読取回数 | 64 | 64 | 64 |
| 新しい接触・離指報告 | 0 | 0 | 0 |

タッチはI2C通信と情報取得の証拠であり、実際の指操作、座標校正、
離指、複数接触の実機確認ではない。VBUSのOFFは制御レジスタの読返しで、
電圧の実測ではない。スキャンアウト、画面更新、ストレージとの同時実行も
この試験では確認していない。CPU1を含む検証負荷の終了後に実行している。

## PowerOffの観測と失敗記録

最初のソース `3a884a8` は残り回数3を読んだが、PowerOffの非活性状態を
確認できず不合格になった。この試行には最終Flash照合の記録がない。
診断用の `da62744` で応答ヘッダを保持し、PowerOff応答は
`type=81 flags=00 error=00 parameter=00 payload_length=0` と観測した。
こちらも不合格だが、インストール前後のFlash照合を保持した。

CCIDの成功応答とICC状態のactive報告が併存している。
[CCID 1.1](https://www.usb.org/sites/default/files/DWG_Smart-Card_CCID_Rev110.pdf)
の状態区分に従い、共通サービスはこれを非活性化の確認として受理していない。
原因は未特定で、リーダーの電波や電圧を測定したわけではない。
確認モードに限り、USB-A給電OFFの読返しを別の終了方式 `poweroff=2`
として記録する。共通サービスの認証済み属性の公開条件は緩和していない。

3つの試行は上書きせず、失敗ログも保持した。
最終試行の厳密な検査器は、給電OFFやDMA消去、PIN無送信、
回数・タッチ情報が欠けた報告を拒否する。
