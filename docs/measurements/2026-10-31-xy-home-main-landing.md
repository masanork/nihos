# xyのホーム・本棚・Tab5読書をmainへ統合する

ホーム、チュートリアル、オフライン本棚、Tab5接続、縦書き欧文の横倒し表示を、
`origin/main` の `e1cfd0ca` に統合した。実装元は `d44186b`、`c85d7ed`、`b507452`。
最新mainの起動スプラッシュとカメラAPIを保持し、統合用作業ツリーを分離した。
元の `/Users/masanork/repo/nihos` のHEAD・未コミット4ファイルは変更しない。

## 利用できること

- MacとTab5がホームで起動する。文書、使い方、草枕、SICP、リポジトリの書籍、設定を選べる。
- Tab5は本・フォントをFlashから参照し、SDやネット接続なしで読める。
  タッチで本・章を開き、本文下部で前後ページ・目次・設定へ移れる。
- 縦書きの英字列は横書きの字形と字送りを時計回りに90度回転する。
  和文・仮名のルビは既存の縦書き処理を使う。
- Macの文書はUTF-8ファイルへ保存でき、表示設定も保存する。
  Tab5の文書・表示設定・読書位置はRAM上に保持し、再起動後の保存は未接続。
- 草枕は全13章、SICPは英語Scheme版3節、リポジトリの書籍は32項目。
  Tab5の図版は説明文で読む。SICP全巻・日本語訳やTab5でのSVG閲覧は含まない。

## mainとの統合で補った点

競合した `diagnostic_ui.beginSession` は、ホームの初期化とカメラproviderの接続を両方残した。
Flash監査は512 glyphの描画予算と、mainのスプラッシュ用関数を保持する。
カメラ検証CLIと旧RAM文書検証ツールは、ホームから `n` で文書へ入ってから入力する。
RV32の文書試験も、Ctrl-C後のホームから文書を再開して画素を比較する。

LinuxのPython全体試験もTab5のシーン試験を発見するため、CI・USBジョブで
プレビューを先にビルドする。MacジョブではMacの文書・読書とTab5のシーンを検証する。
READMEと端末操作の説明をホーム起動に合わせた。

最初の統合リンクはheapが49,088 bytesとなり、48KiB下限に64 bytes足りず停止した。
診断専用のリンカースクリプトのコピーで配置だけを調べ、診断用ELFは実機へ書いていない。
製品用リンカーの49,152 bytes下限は変更せず、診断画面の不変見出しをFlashへ移した。
最終trace版は49,216 bytes、通常版は49,344 bytesのprimary SRAM heapを保持する。
keypad/card-read/card-autoの既存payloadを変えず、リンカーソースのhashだけを更新し、
関連6試験でソース・payloadの一致を再確認した。

## 初回統合版のTab5検証

ESP32-P4 rev1.3、MAC `e8:f6:0a:e2:e8:9c` を識別し、書込みロックとcu/ttyの排他を取得した。
直前の横倒し版の16MiB Flash期待値を私有バックアップとして再利用し、
書込み前に実機全体と一致することを確認した。監査済み候補を固定して書き込み、
候補のreadbackに加えて、変更セクタを重ねた16MiB全体の期待値との一致を検証した。
変更セクタ外とSDを保持した。生のFlash・復元用断片・バイナリを公開証跡へ入れない。

統合版の29観測が成功した。ホーム、草枕、SICP、書籍、縦横・サイズ・書体・明暗、
ページの前後、文書のホーム往復、再起動後のホームを確認した。
最大描画スタック使用量は142,368 bytes、確保は従来どおりガード付き262,144 bytes。
最後はSICP 1.1を32px・明朝・縦書きで開いて残した。

導入した統合trace appのSHA-256：

```text
d8c818e308f85524fd1e33f9c142597785324dd0ccc0f9f306f2182e4321e1db
```

通常版は `3b9d2f4ea54498971af022875b5abbab164c01c9eba4d64756f71ce57bd9381e`。

冷間電源投入、文書保存、電断復旧、長時間連続読書を今回の合格範囲には含めない。

## レビュー修正後の最終候補

PR #92のレビューで見つかった2件を修正した。

- Macで文書を新規作成・読込する際に、前の文書のIME reading・候補選択を破棄する。
  入力モードと独自prefix登録は保持する。旧版で `newOLDカ` と混入する再現試験が失敗し、
  修正版では未確定文字列の混入なし、カタカナ入力・独自prefix保持の試験が成功した。

  前章の最終ページへ戻った後、さらにその前のページにも戻れる。
  章を目次から選び直すと履歴を初期化し、履歴外の前章へは先頭から開く。
  未描画の位置からNextを連続処理して章を飛ばすことも防いだ。
