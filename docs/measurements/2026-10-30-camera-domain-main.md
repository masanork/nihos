# Shared display/camera DMA domain admission (2026-10-30)

Base `d824feaa8acc66dc16810fc9fa95887f5efc642d` plus uncommitted camera integration changes. Display scanout channel 0 and the opt-in camera channel 1 now share CPU0-serialized DW-GDMA domain ownership. An already-clocked external owner is never reset. Shared controller fault status is sampled once and copied to all live channel owners; a fault blocks further admission. Display stop releases only its own channel and disables the shared controller only after the last channel is gone. Camera admission checks channel 1 is not enabled, has no pending status and no FIFO contents; its unused lease can be released only while its interrupt masks match their admission snapshot and no common fault occurred. A started lease has no release path and remains pinned.

One Tab5 ESP32-P4 rev 1.3 trial, MAC `e8:f6:0a:e2:e8:9c`, explicitly requested `:camera-domain` with `NIHOS_NATIVE_CAMERA_ID=1`, network and normal storage disabled. App SHA-256 `f06c09fb3884e313e0cf83c52a95ca1503fd25e8640a9f45024ad4a3bf74430e`, ELF SHA-256 `21f13dbb4632414c019d3a8d475f7bf71b67db934eaedf19114ba7ce2a89cfeb`. [Receipt and image audit](evidence/2026-10-30-camera-domain-main/). The channel was acquired and released unused; periodic state 3/result 1 reports repeated the same one trial. Launcher ready, display frame count and CPU counters progressed across the request. No channel 1 DMA transfer was started.

Host shared-domain replay exercises busy and stale admission, pending common errors, retention after marking a channel started, and refusal to release an uncertain lease. Display retirement replay covers cross-owner preservation and last-owner shutdown; notice and card simulator tests passed. Debug Zig tests and both opt-in and default native image audits passed. The domain policy uses CPU0 and local interrupt exclusion; it does not establish safety for arbitrary concurrent cross-core RCC/DMA users. Host tests do not model silicon bus races or DMA FIFO drain. Normal/default physical boot, other active peripheral coexistence and panel appearance were not independently tested in this run.

The original loader and app erase spans (24,576 and 155,648 bytes) were restored and full readback verified, followed by a hard reset; restored-system boot was not captured. Raw serial logs remain private. Transferring bytes and safely reclaiming a started channel or frame remain unqualified.
